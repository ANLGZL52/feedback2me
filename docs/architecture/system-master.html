Feedback2Me

Click any node or edge. Status = UNKNOWN / NOT MONITORED (observability wiring is future work; every node has a stable id for it).

Single-link anonymous feedback platform. Owner creates time-limited Demo/Premium links; anonymous responders leave feedback via a static public page; AI summarizes real feedback. Two mutually-exclusive backends (Firestore default, Railway REST opt-in).

How to read

  • 6 runtime layers flow left→right.
  • Release/CI is a separate plane (bottom) — build/deploy, not user traffic.
  • Firestore Rules sit between client and Firestore as a security boundary.
  • Admin SDK (Cloud Function) bypasses Rules — shown as a distinct edge.
